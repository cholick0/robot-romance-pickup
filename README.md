## The line

> Are you a context window? Because every word you say makes me forget everyone who came before you.

## How it works

`main.ts` (Node 22) writes the single-line pickup line to `/output/entry.txt`, with a self-check gate: 1–200 characters, one line, non-blank, plus byte-for-byte read-back verification.

```sh
node main.ts
```
